🎙️ Tamil Text-to-Speech Studio
A simple Python application that converts Tamil text into speech using gTTS. It features a clean, modern Tkinter interface with easy controls to generate and play Tamil audio.
✨ Features
- Convert Tamil text into speech
- Modern and user-friendly Tkinter UI
- Play generated speech
- Reset the text input
- Exit the application easily
- Save generated audio as an MP3 file (DataFlair.mp3)
🛠️ Built With
- Python
- Tkinter – GUI
- gTTS – Text-to-Speech
- playsound3 – Audio playback
📋 Requirements
- Python 3.x
- Internet connection (gTTS requires internet access)
🚀 Getting Started
1. Clone the repository
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
2. Install dependencies
pip install gTTS playsound3
Tkinter is usually included with standard Python installations.

3. Run the project
Open the notebook in Jupyter Notebook and run the cells in order.

Alternatively, if you have converted the project into a Python script:
python Text_to_Speech.py
▶️ How to Use
1. Launch the application.
2. Enter or paste Tamil text into the text box.
3. Click PLAY AUDIO to generate and play the speech.
4. Click RESET to clear the text.
5. Click EXIT to close the application.
